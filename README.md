# Iris Dataset Analysis


This practical focuses on exploring and analyzing the Iris dataset using Python and Pandas.

## Objectives

* Load the Iris dataset
* Explore the dataset using Pandas
* Check the shape and structure of the dataset
* Display column names and data types
* Check for missing values
* Identify unique species
* Count the number of records for each species
* Calculate mean, median and standard deviation
* Remove the `Id` column

## Practical Work

The Iris dataset contains 150 records and 6 columns. The practical uses Pandas functions such as `head()`, `sample()`, `shape`, `columns`, `dtypes`, `isnull()`, `unique()`, `value_counts()`, `mean()`, `median()`, and `std()` for data exploration and analysis.

The dataset contains three species: Iris-setosa, Iris-versicolor and Iris-virginica, with 50 records for each species.
